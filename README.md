## Hi, I'm Usama

I'm a **frontend-focused MERN stack developer** based in Lahore, Pakistan. I build responsive websites and web apps with React and Next.js, with a focus on clean design, smooth interactions and practical functionality.

My work includes company websites, UK service businesses, e-commerce interfaces and portfolios with admin panels and AI chatbots. I also work with Node.js, Express.js, MongoDB and Supabase to connect the interface to the data and features behind it.

**Open to frontend developer opportunities and MERN stack internships.**

- Turning designs into responsive layouts and reusable React components.
- Adding animations and interactive 3D elements with Framer Motion, Three.js and React Three Fiber.
